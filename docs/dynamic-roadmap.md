# 后续动态化建议

## 1. 题库动态化

当前题库放在 `public/assets/js/data/questions.js`，部署简单、访问快。后续如果要在线更新题库，可以迁移为：

- `/api/questions`：从 D1 或 KV 读取题库
- `/api/questions/import`：管理员上传 JSON 或表格后自动解析
- `question_versions`：记录不同学期、不同老师版本

## 2. 学习记录

可以用 Cloudflare D1 存储：

- 用户基础信息
- 每题作答记录
- 错题本
- 正确率变化
- 复习报告

## 3. AI 能力

当前 AI 只做讲解、口诀、周报。后续可以加：

- 按专题归纳错题
- 自动生成同类题
- 高频考点预测
- 考前 30 分钟速背清单

## 4. 和主观题资料联动

后续可把 `01_全文高亮.md`、`02_重点摘录.md`、`03_重点背诵版.md` 转为专题知识库，让客观题讲解能跳转到对应主观题背诵材料。
